## ¡Te damos la bienvenida!

¡Hola a todos! Estoy encantado de ser vuestro profesor. Este curso, vamos a embarcarnos en un viaje para descubrir cómo se crean experiencias digitales que no solo son bonitas, sino también intuitivas y accesibles para todos los usuarios.

---

## ¿Qué vas a aprender?

- **🎯 Objetivo Principal:** Al finalizar el curso, serás capaz de planificar, diseñar e implementar interfaces web completas, integrando usabilidad y accesibilidad.
- **🚀 Construyendo sobre una base:** A partir de la base de HTML y CSS de primero usaremos esos conocimientos como punto de partida para ir mucho más allá!

---

## Nuestro Plan de Viaje

Este es el recorrido que haremos juntos:

| Unidad | Título | Descripción | Estado |
| :---: | :--- | :--- | :---: |
| **UD1** | **[Planificación de Interfaces Gráficas](UD1_Planificacion_Interfaces/01_Planificacion_de_Interfaces.md)** | Aprenderemos a pensar como diseñadores, creando bocetos y flujos de usuario antes de tocar una sola línea de código. Es la base para construir proyectos sólidos y centrados en el usuario. | Material disponible |
| **UD2** | **Accesibilidad en la Web** | Nos centraremos en un pilar fundamental: asegurar que cualquier persona, sin importar sus capacidades, pueda usar nuestras creaciones sin barreras. La web es para todos. | Próximamente |
| **UD3** | **Usabilidad** | Descubriremos los principios para crear interfaces intuitivas y fáciles de usar. Un buen diseño no solo es bonito, sino que también funciona de manera eficiente y satisfactoria para el usuario. | Próximamente |
| **UD4** | **Creación de Interfaces utilizando Estilos** | Nos sumergiremos de lleno en el código, donde dominarás las técnicas de maquetación y diseño visual con CSS para construir interfaces web modernas y adaptables a cualquier dispositivo. | Próximamente |
| **UD5** | **Integración de Contenido Multimedia** | Aprenderemos a enriquecer nuestras interfaces con imágenes, vídeo y audio, optimizando su rendimiento y garantizando una experiencia visualmente atractiva. | Próximamente |
| **UD6** | **Interactividad** | Cerraremos el curso añadiendo elementos dinámicos que harán que tus proyectos cobren vida. La interactividad es clave para crear experiencias de usuario memorables y funcionales. | Próximamente |
