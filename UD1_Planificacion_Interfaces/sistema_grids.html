1️⃣ 8pt Grid System (Espaciado)

TODO el espaciado y tamaños deben ser múltiplos de 8px: padding, margin, gaps, alturas, anchos...

🎯 ¿Para qué sirve el 8pt Grid?
El 8pt Grid se usa para TODOS los espaciados y tamaños en tu diseño:
• Espacio entre elementos (margins)
• Espacio interno de componentes (padding)
• Separación entre items (gaps)
• Altura de botones, cards, headers
• Cualquier medida que uses

Regla simple: Si mides algo, debe ser múltiplo de 8.

2️⃣ Layout Grid (Organización del Ancho)

Para decidir cuánto ANCHO ocupan los contenedores principales en tu página. Desktop 12 columnas, Tablet 8, Mobile 4.

🎯 ¿Para qué sirve el Layout Grid?
El Layout Grid (columnas) se usa SOLO para decidir el ANCHO de contenedores:
• ¿Cuántas cards caben por fila? (3 cards = 4 columnas cada una)
• ¿Cuánto ancho ocupa el sidebar? (4 de 12 columnas)
• ¿El contenido principal? (8 de 12 columnas)

NO se usa para espaciados internos, botones, textos o elementos pequeños.
Para eso está el 8pt Grid.

📱 Ventaja de usar Stretch
Al configurar el tipo como "Stretch", las columnas se adaptan automáticamente al ancho del frame. No necesitas calcular el ancho de cada columna - Figma lo hace por ti. Esto hace que el grid sea totalmente responsive y funcione en cualquier tamaño de pantalla.
🎯 Cómo usar las columnas
Las columnas son una GUÍA, no límites rígidos. Tu contenido puede ocupar:

• Desktop (12 col): 3 cols (cuarto), 4 cols (tercio), 6 cols (mitad), 8 cols (dos tercios), 12 (completo)
• Tablet (8 col): 2 cols (cuarto), 4 cols (mitad), 8 cols (completo)
• Mobile (4 col): Generalmente 4 cols (ancho completo)

🎨 Cómo Configurar en Figma

Paso a paso para configurar tu sistema de grids en Figma

📐 Configuración del Layout Grid
1 Selecciona tu Frame principal (ej: Desktop 1440px)
2 En el panel derecho, busca "Layout Grid" y haz clic en "+"
3 Cambia el tipo de "Grid" a "Columns"
4 Configura los valores para Desktop:
• Count (Número de columnas): 12
• Type: Stretch (para que se adapten al frame)
• Gutter (Espacio entre columnas): 24
• Margin (Espacio desde los bordes): 80
5 Opcional: Cambia el color y opacidad del grid
• Haz clic en el cuadrado de color junto a "Layout grid"
• Color: Rojo o morado claro
• Opacity: 10-20% (para verlo sin que moleste)
6 Para Tablet y Mobile, crea frames separados con sus propias configuraciones
• Tablet: 8 columnas, Gutter 24px, Margin 40px
• Mobile: 4 columnas, Gutter 16px, Margin 16px
📏 Activar el 8pt Grid en Figma
1 Ve a Preferences (Cmd/Ctrl + ,)
2 En la sección "Nudge amount", configura:
• Small nudge: 8px (flechas del teclado)
• Big nudge: 16px (Shift + flechas)
3 Opcional: Añade un grid visual de 8px a tu frame
• Layout Grid → Click en "+"
• Mantén tipo "Grid" (cuadrícula)
• Size: 8px
• Opacity: 5% (muy sutil, solo para referencia)
4 Ahora al mover elementos con las flechas, se moverán de 8 en 8 píxeles automáticamente
💡 Tip profesional
Crea un "Frame Template" con el grid ya configurado y guárdalo como componente. Así no tienes que configurarlo cada vez. Puedes tener tres templates: Desktop (12 col), Tablet (8 col), Mobile (4 col).

✨ Resumen: Los 2 Sistemas de Grids

8️⃣

8pt Grid System

Para ESPACIADO y TAMAÑOS. TODO debe ser múltiplo de 8px.

Usa SIEMPRE para:
• Padding (interno de elementos)
• Margin (externo entre elementos)
• Gaps (espacios en flex/grid)
• Alturas de elementos
• Anchos cuando sean fijos
• Border radius (opcional, múltiplo de 4)
• CUALQUIER distancia o tamaño
📐

Layout Grid (Columnas)

Para ORGANIZAR el ANCHO de contenedores. Desktop 12, Tablet 8, Mobile 4.

Usa SOLO para decidir el ANCHO de:
• Contenedores principales
• Cards (¿ocupa 4 o 6 columnas?)
• Secciones (main 8 cols + sidebar 4 cols)
• Grids de productos
• Layout general de la página

⚠️ NO para elementos internos como botones, textos, iconos

🎯 Regla de Oro: Cuándo usar cada uno

📐 ¿Pregunta sobre ANCHO de contenedores? → Layout Grid (Columnas)
"¿Cuántas cards caben por fila?"
"¿Cuánto ancho ocupa el sidebar?"
"¿La card ocupa 4 o 6 columnas?"
→ Usa las columnas del grid
8️⃣ ¿Pregunta sobre ESPACIOS o TAMAÑOS? → 8pt Grid
"¿Cuánto padding le pongo a la card?"
"¿Qué espacio dejo entre el título y el precio?"
"¿Qué gap pongo entre botones?"
"¿Qué altura tiene el botón?"
→ Usa múltiplos de 8 (8px, 16px, 24px, 32px...)

✅ Checklist Final

  1. 8pt Grid es OBLIGATORIO para TODO - Cada medida debe ser múltiplo de 8
  2. Layout Grid desde el wireframe - Configúralo en Desktop (12 col), Tablet (8 col), Mobile (4 col)
  3. Type: Stretch siempre - Las columnas se adaptan al ancho del frame
  4. El grid se oculta al exportar - Ctrl/Cmd + G para mostrar/ocultar
  5. Revisa antes de finalizar - ¿Todo es múltiplo de 8? ¿Los contenedores siguen las columnas?
