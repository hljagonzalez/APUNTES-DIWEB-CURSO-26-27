🔧 Crear Componentes de Iconos con Variantes en Figma

Aprende a crear un sistema de iconos reutilizable y flexible con variantes múltiples

1 Importar icono desde biblioteca de Figma
• Ve a Assets (panel izquierdo) o presiona Shift + I
• Busca "Simple Design System" o cualquier biblioteca con iconos
• Arrastra un icono a tu canvas (ej: icono "Star")
• Repite para otro icono diferente (ej: icono "Repeat")
2 Hacer Detach del icono
• Selecciona el icono importado
• Click derecho → "Detach instance" (o Cmd/Ctrl + Alt + B)
• Ahora el icono es tuyo y puedes modificarlo
• Repite el Detach para el segundo icono
3 Preparar los dos iconos base
• Asegúrate que ambos iconos (Star y Repeat) tengan tamaño 24×24px
• Cambia ambos iconos a color Negro (#000000)
• Renombra el primer icono a "Star"
• Renombra el segundo icono a "Repeat"
• Colócalos uno al lado del otro con espacio entre ellos
4 Crear componentes múltiples con variantes (IMPORTANTE)
• Selecciona AMBOS iconos (Star y Repeat)
• Click derecho → "Create multiple components" (o Cmd/Ctrl + Alt + Shift + K)
• IMPORTANTE: En el diálogo que aparece, marca la opción "Combine as variants" ✓
• En el campo de la propiedad, escribe "Type"
• Figma creará automáticamente un componente con la propiedad "Type" con valores: Star, Repeat
• Ahora tienes un componente con 2 variantes base
5 Renombrar componente y añadir variantes de Size
• Selecciona el componente principal (el contenedor morado que engloba ambos iconos)
• En el panel derecho, renómbralo a "Icons"
• Ahora entra en el componente haciendo doble click
• Selecciona UNA de las variantes existentes (ej: Star)
• Duplica esa variante (Cmd/Ctrl + D) y colócala al lado
• Cambia el tamaño del duplicado a 12×12px
• Repite el proceso para la otra variante (Repeat)
• Sal del componente y selecciona el componente principal (el contenedor morado completo)
• En el panel derecho, haz click en el + para añadir una nueva propiedad
• Selecciona el tipo "Variant"
• Escribe el nombre de la propiedad: "Size"
• Entra nuevamente en el componente
• Asigna valor "24" a los de 24px y "12" a los de 12px
• Ahora tienes 4 variantes: Star-24, Star-12, Repeat-24, Repeat-12
6 Añadir propiedad Color
• Dentro del componente, selecciona TODAS las variantes actuales (Star-24, Star-12, Repeat-24, Repeat-12)
• Duplica todas (Cmd/Ctrl + D)
• Cambia el color de los duplicados a Blanco (#FFFFFF)
• Sal del componente y selecciona el componente principal (el contenedor morado completo)
• En el panel derecho, haz click en el + para añadir una nueva propiedad
• Selecciona el tipo "Variant"
• Escribe el nombre de la propiedad: "Color"
• Entra nuevamente en el componente
• Asigna valor "Black" a los negros y "White" a los blancos
• Ahora tienes 8 variantes totales (2 tipos × 2 tamaños × 2 colores)
7 Organizar las variantes
• Dentro del componente, organiza las 8 variantes en una cuadrícula lógica
• Agrupa por Type (Star arriba, Repeat abajo) o por Size/Color
• Mantén espaciado consistente entre variantes (múltiplos de 8px)
• Verifica que todas las propiedades estén correctamente asignadas
• Sal del modo edición del componente haciendo click fuera
8 Usar el componente con variantes
• Ve a Assets (Shift + I)
• Busca tu componente "Icons"
• Arrástralo a tu diseño
• En el panel derecho verás dropdowns para: Type, Size, Color
• Cambia entre las 8 variantes fácilmente ¡sin duplicar componentes!
• Cada cambio de propiedad actualiza el icono instantáneamente

🎯 Resultado Final

Tendrás UN solo componente llamado "Icons" con 3 propiedades que combinan para crear 8 variantes:

Propiedades del componente:
• Type: Star, Repeat
• Size: 24, 12
• Color: Black, White

Total de combinaciones: 2 × 2 × 2 = 8 variantes
Ventaja clave: Usar "Combine as variants" desde el principio crea la estructura correcta. Luego solo añades más propiedades dentro del componente.
✨ Por qué este método es mejor
• Más rápido: Creas la estructura de variantes desde el inicio
• Más limpio: Figma organiza automáticamente las propiedades
• Más escalable: Añadir nuevos iconos es solo duplicar dentro del componente
• Menos errores: No necesitas seleccionar todo al final y esperar que Figma detecte patrones
• Profesional: Es el flujo de trabajo estándar en equipos de diseño
⚠️ Errores comunes a evitar
• NO olvides marcar "Combine as variants" - Sin esto, crearás componentes separados
• NO crees todas las variantes ANTES - Es más difícil de manejar y organizar
• NO uses nombres inconsistentes - "Star", "star", "STAR" son diferentes para Figma
• NO mezcles formatos - Si usas "24" para size, no uses "Small" para otro
• Para cambiar colores, haz DETACH en la propiedad Fill - Los iconos importados están vinculados a la biblioteca original y no podrás cambiar su color hasta hacer detach (quitar el clip)
• Ten cuidado con Frame vs Icono - Cada componente tiene un marco contenedor y el icono dentro. Asegúrate de seleccionar el correcto:
   → Para añadir propiedades: selecciona el componente/frame principal
   → Para cambiar color/tamaño: selecciona el icono interior
   → Mira la jerarquía en el panel izquierdo para verificar qué tienes seleccionado
• Usa el botón + para crear variantes DENTRO del componente - NO uses copiar/pegar (Cmd/Ctrl + C y V) para duplicar variantes. Esto creará elementos fuera del componente. Siempre duplica usando Cmd/Ctrl + D mientras estás DENTRO del componente, o usa el botón + en las propiedades
• Ajusta el stroke en tamaños pequeños - Cuando crees iconos de 12px o menores, considera reducir el grosor del trazo (stroke). Un icono de 24px con stroke de 2px se verá bien, pero al reducirlo a 12px puede verse demasiado grueso. Ajusta el stroke proporcionalmente para mantener la legibilidad
• Organiza las variantes dentro del componente - Facilita el mantenimiento visual
