## Introducción

> Antes de escribir una sola línea de código, el diseño de una interfaz web comienza en la fase de planificación. En este tema, exploraremos los principios fundamentales para sentar las bases de cualquier proyecto, desde la comprensión de la percepción visual hasta la creación de mapas y prototipos. Nos centraremos en construir un plan sólido para garantizar que nuestras interfaces sean intuitivas y efectivas desde el inicio.

---

## Puntos clave del tema

### 1. 👀 Elementos del diseño: percepción visual
Explora cómo el cerebro humano interpreta lo que ve. Aprenderemos a aplicar principios como la Gestalt para crear diseños que sean intuitivos y fáciles de procesar para el usuario.

### 2. 🎨 Color, tipografía, iconos
Estos son los bloques de construcción visuales de cualquier interfaz. Su correcta selección no solo hace que un diseño sea atractivo, sino que también establece el tono y guía al usuario sin necesidad de palabras.
* 📄 **Guía detallada de color:** [Guía Completa: Paletas de Color para Diseño Web](Guia_Paletas_Color.md)
* 📄 **Guía detallada de tipografía:** [Sistema Tipográfico Completo para Diseño Web](Sistema_Tipografico.md)
* 📄 **Guía detallada de iconografía:** [Sistema de Iconografía para Design System](Sistema_Iconografia.md)

### 3. 🧠 Interacción persona-ordenador
Se enfoca en cómo las personas interactúan con las interfaces digitales. Nuestro objetivo es diseñar una interacción que sea fluida, eficiente y que cause la menor frustración posible.

### 4. 📖 Interpretación de guías de estilo
Es el proceso de entender y aplicar un conjunto de normas visuales predefinidas. Esto asegura la coherencia de marca, el diseño y la usabilidad en un proyecto.
* 📝 **Actividad / Autoevaluación:** [Cuestionario sobre Guías de Estilo de Marca](Cuestionario_Guias_de_Estilo.md)

### 5. 📐 Patrones de diseño Web
Son soluciones probadas y reutilizables para problemas de diseño comunes. Por ejemplo, el patrón de "barra de navegación" o el de "formulario de inicio de sesión".

### 6. ✍️ Generación de documentos y sitios Web
El proceso de crear la estructura y el contenido de una página web, desde el boceto inicial hasta la implementación final.

### 7. 🧩 Componentes de una interfaz Web
Las partes individuales que forman una interfaz, como botones, menús, campos de texto y barras de desplazamiento.
* 🔘 **Guía monográfica de componentes:** [Sistema de Botones para Design System](Sistema_Botones.md)

### 8. 💻 Aplicaciones para desarrollo Web
Son las herramientas y programas que los diseñadores y desarrolladores usan para crear interfaces, como Figma para prototipos o VS Code para codificación.
* 🛠️ **Guía práctica de Figma:** [Colaboración y Organización en Figma](Guia_Figma.md)

### 9. 🏷️ Lenguajes de marcas
Son la base de la web. HTML se usa para estructurar el contenido, mientras que CSS le da estilo y diseño a la página.

### 10. 🗺️ Mapa de navegación. Prototipos
El mapa de navegación es el esqueleto de un sitio, mostrando la jerarquía de las páginas. Los prototipos son maquetas interactivas para probar cómo se sentirán los usuarios al usar la interfaz.

### 11. 🏗️ Maquetación Web. Elementos de ordenación
Se trata de organizar visualmente los elementos en la página. Aborda la jerarquía, el equilibrio y la alineación para crear un diseño armonioso y fácil de leer.
* 📐 **Guía detallada de maquetación:** [Sistema de Grids para Design System](Sistema_Grids.md)

### 12. 🗂️ Marcos, tablas y capas
Son diferentes métodos para estructurar el contenido en la página. Las capas (usando divs y CSS) han reemplazado en gran medida a los marcos y las tablas para la maquetación.

### 13. 📄 Plantilla de diseño
Una estructura predefinida que se usa para crear múltiples páginas con un diseño coherente. Esto ahorra tiempo y asegura la uniformidad en todo el sitio.
