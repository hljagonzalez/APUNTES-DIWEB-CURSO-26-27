📏 Escala Tipográfica Completa

Todos los niveles de jerarquía que necesitas en tu sistema de diseño

H1 - Hero/Display 72px • 800 (ExtraBold) • Line-height 1.1
El título más importante
Uso: Títulos principales de página, heroes, landing pages. Solo 1 por página.
H2 - Section Heading 48px • 700 (Bold) • Line-height 1.2
Título de sección principal
Uso: Títulos de secciones principales, divisiones importantes del contenido.
H3 - Subsection 32px • 600 (SemiBold) • Line-height 1.3
Subsección o título de card
Uso: Subsecciones, títulos de cards grandes, bloques de contenido destacados.
H4 - Component Title 24px • 600 (SemiBold) • Line-height 1.4
Título de componente
Uso: Títulos de componentes pequeños, cards medianas, modales.
H5 - Label/Subtitle 18px • 600 (SemiBold) • Line-height 1.4
Label o subtítulo destacado
Uso: Labels importantes, subtítulos, categorías, metadatos destacados.
Body - Texto principal 16px • 400 (Regular) • Line-height 1.6
Este es el texto principal que se usa para párrafos, descripciones largas y la mayor parte del contenido. Debe ser muy legible y cómodo de leer en bloques largos de texto.
Uso: Párrafos, descripciones, contenido principal. El 70% de tu texto.
Body Small - Texto secundario 14px • 400 (Regular) • Line-height 1.5
Texto secundario más pequeño para información complementaria, descripciones breves o metadatos.
Uso: Texto secundario, metadatos, fechas, información complementaria.
Caption - Anotaciones 12px • 400 (Regular) • Line-height 1.4
Pie de foto, notas al pie, timestamps, información terciaria
Uso: Pies de foto, notas, timestamps, información muy secundaria.
Button - Botones y CTAs 16px • 600 (SemiBold) • Line-height 1
Botón de acción
Uso: Todos los botones, CTAs, elementos interactivos importantes.

🎨 Opciones: 1 vs 2 Fuentes

Compara las diferentes aproximaciones y elige la que mejor se adapte a tu proyecto

✅ Opción 1: Una sola fuente (Inter)
Bienvenido a nuestra plataforma
Subtítulo descriptivo del contenido
Inter es una fuente versátil que funciona perfectamente tanto para títulos como para texto corrido. Es la opción más segura y profesional para aplicaciones web y dashboards modernos.
✓ Mejor para: Apps, dashboards, plataformas SaaS, diseños minimalistas, proyectos profesionales
✨ Opción 2: Dos fuentes - Moderna (Poppins + Inter)
Bienvenido a nuestra plataforma
Subtítulo descriptivo del contenido
Esta combinación usa Poppins para títulos (más personalidad) e Inter para texto corrido (máxima legibilidad). Perfecta para proyectos que necesitan destacar visualmente.
✓ Mejor para: Landing pages, sitios corporativos modernos, startups, productos creativos
🎩 Opción 3: Dos fuentes - Elegante (Playfair + Inter)
Bienvenido a nuestra plataforma
Subtítulo descriptivo del contenido
Playfair Display aporta elegancia y sofisticación a los títulos, mientras que Inter mantiene la legibilidad en el texto. Contraste serif-sans serif muy efectivo.
✓ Mejor para: Blogs, revistas digitales, marcas de lujo, contenido editorial, portfolios
💡 Consejo profesional
¿Cuál elegir? Si tienes dudas, empieza con una sola fuente (Inter, Roboto o Poppins). Es más fácil de mantener consistente y siempre se ve profesional. Usa dos fuentes solo si realmente aporta valor a tu marca o contenido.

🎯 Observa la jerarquía - Qué estilo usar en cada elemento

  • Logo → H4 (24px, 600): Título de componente, destaca sin dominar
  • Navegación → Body (16px, 400): Texto principal, legible y secundario
  • Hero título → H1 (72px, 800): El protagonista absoluto de la página
  • Hero descripción → Body (16px, 400): Texto principal estándar
  • Botones → Button (16px, 600): Estilo específico para CTAs
  • Título de sección → H2 (48px, 700): Títulos de secciones principales
  • Título de card → H4 (24px, 600): Títulos de componentes individuales
  • Descripción de card → Body (16px, 400): Texto principal, fácil de leer
  • Metadata de card → Body Small (14px, 400): Información secundaria

✨ Reglas de Oro para Tipografía

1️⃣

Máximo 2 fuentes

Más de dos fuentes crea confusión visual. Una sola fuente versátil es mejor que tres mediocres.

2️⃣

Jerarquía clara

La diferencia entre H1 y H2 debe ser obvia. Mínimo 8-12px de diferencia entre niveles.

3️⃣

Line-height correcto

Títulos: 1.1-1.3. Texto corrido: 1.5-1.6. Nunca menos de 1.4 para legibilidad.

4️⃣

Contraste suficiente

Si usas dos fuentes, que sean claramente diferentes. Serif + Sans-serif funciona siempre.

5️⃣

Peso variable

Importa mínimo 3 pesos: Regular (400), SemiBold (600), Bold (700) para crear jerarquía.

6️⃣

16px mínimo

El texto principal nunca debe ser menor de 16px. Es el estándar de legibilidad web.

🎯 Proceso recomendado para tus alumnos

  1. Elige 1 fuente versátil (Inter, Roboto, Poppins) o una combinación de 2
  2. Define tu escala tipográfica usando Type Scale
  3. Importa los pesos necesarios: 400, 500, 600, 700
  4. Crea estilos en Figma para cada nivel (H1-H5, Body, etc.)
  5. Aplica en un diseño real y ajusta si es necesario
  6. Documenta tu sistema para mantener consistencia

📚 Resumen Ejecutivo

¿Cuántas fuentes?

1 fuente versátil (más común) o 2 fuentes con contraste claro (más expresivo). Nunca 3+.

¿Qué pesos importar?

Mínimo: 400, 600, 700 | Ideal: 400, 500, 600, 700, 800

¿Cuántos tamaños necesito?

9 niveles: H1, H2, H3, H4, H5, Body, Body Small, Caption, Button

Herramientas esenciales

Google Fonts (buscar), FontPair (combinar), Type Scale (escalar)

Regla más importante

La jerarquía debe ser OBVIA. Si dudas si se nota la diferencia, hazla más grande.
