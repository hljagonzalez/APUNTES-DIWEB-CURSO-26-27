### ✅ Reglas de Oro

1. **No uses todos los colores en todos lados:** cada uno tiene su momento.
2. **El color primario con moderación:** solo 2-3 elementos por pantalla.
3. **Los neutros hacen el 80% del trabajo:** estructura, texto y espacios.
4. **Los colores vivos llaman la atención:** úsalos estratégicamente.

## Parte 2: Generar una Paleta desde UN Solo Color

Proceso completo para crear una paleta profesional partiendo de un solo color base.

### Paso 1: Empezamos con UN color base
* Color elegido: **Rosa vibrante (`#e11d48`)**.
* *Punto de partida:* Este puede ser el color de tu marca, logo o el color principal de partida. Desde aquí generaremos toda la paleta completa.

### Paso 2: Generamos variantes monocromáticas
Mismo color en diferentes intensidades (de muy claro a muy oscuro):
* **Rosa 50 (`#fdf2f8`):** Fondos suaves.
* **Rosa 100 (`#fce7f3`):** Cards y secciones destacadas.
* **Rosa 300 (`#f9a8d4`):** Elementos suaves e ilustraciones.
* **Rosa 600 (`#e11d48` - BASE):** Botones principales y llamadas a la acción.
* **Rosa 700 (`#be185d`):** Estados hover.
* **Rosa 800 (`#9f1239`):** Textos oscuros con acento.

> **Cómo hacerlo:** En herramientas como *Coolors.co*, pega `#e11d48`, bloquéalo con el candado y ajusta los deslizadores de luminosidad para crear estas variantes.

### Paso 3: Añadimos un color complementario
El opuesto en la rueda cromática para crear contraste:
* **Color Original:** Rosa (`#e11d48`) — Para elementos principales.
* **Complementario:** Cian (`#0891b2`) — Para elementos secundarios.

> **Teoría del color:** Los colores complementarios están opuestos en la rueda cromática (Rosa-Cian, Azul-Naranja, Verde-Rojo). Crean máximo contraste visual.

### Paso 4: Completamos con neutros
Los grises hacen el 80% del trabajo (textos, fondos y bordes):
* `#ffffff`: Fondos principales.
* `#f9fafb`: Secciones alternas.
* `#e5e7eb`: Bordes y separadores.
* `#9ca3af`: Texto suave y placeholders.
* `#6b7280`: Texto normal de lectura.
* `#374151`: Texto fuerte y subtítulos.
* `#111827`: Títulos principales.

### Paso 5: Paleta aplicada en diseño real
Observa cómo cada color tiene su función:
- **Logo:** Principal (`#e11d48`).
- **Navegación:** Neutro (`#6b7280`).
- **Títulos:** Neutro oscuro (`#111827`).
- **Botones:** Principal (`#e11d48`) + Secundario (`#0891b2`).
¡Todo cohesivo partiendo de un solo color!

## 🛠️ Herramientas recomendadas

- **Coolors.co:** La más fácil de usar. Pega tu color, bloquéalo y genera variantes automáticamente.
- **Adobe Color:** Basada en teoría del color. Perfecta para complementarios y triadas.
- **Material Design Color Tool:** Genera paletas estilo Material Design con variantes automáticas.
- **Paletton.com:** Más técnica pero muy precisa. Ideal para entender teoría del color.

---

## 📚 Resumen: El Proceso Completo

1. 1️⃣ **Un color base:** Tu color principal o de marca.
2. 2️⃣ **Variantes:** 5-7 tonos del mismo color.
3. 3️⃣ **Complementario:** Color opuesto para contraste.
4. 4️⃣ **Neutros:** 7-10 grises para estructura.

### 💡 Recuerda siempre
- Cada color tiene un **PROPÓSITO**, no es simple decoración.
- Los neutros hacen el **80% del trabajo visual**.
- El color primario debe usarse con **moderación**.
- Siempre verifica la accesibilidad (**contraste 4.5:1 mínimo**).
